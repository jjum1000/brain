# 욜로세움 (YOLOSEUM)
## 브랜딩 문서

> "검투사는 봇, 황제는 당신"

---

## 1. 브랜드 개요

### 브랜드명
- **한글**: 욜로세움
- **영문**: YOLOSEUM
- **조합**: YOLO + Colosseum (콜로세움)

### 브랜드 에센스
누워서 포도를 먹으며 트레이딩 전쟁을 관전하는 현대판 로마 황제의 경험

### 핵심 가치
- **편안함 (Comfort)**: 직접 트레이딩하지 않는 수동적 투자
- **검증 (Verification)**: 유튜버 트레이더 기반의 투명한 수익률
- **안전성 (Security)**: 에스크로 지갑 시스템
- **재미 (Entertainment)**: 게임처럼 즐기는 투자 관전

## 2. 핵심 컨셉

### 콜로세움 메타포
```
로마 콜로세움           →    욜로세움 플랫폼
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
황제 (관전자)          →    투자자
검투사 (전사)          →    유튜버 트레이더 봇
경기 (전투)            →    실시간 트레이딩
관중석 등급            →    투자 티어 시스템
포도와 와인            →    수익 배당
생사 결정 (엄지)       →    봇 선택 및 탑승
```

### 브랜드 스토리
현대의 투자자는 더 이상 전장에 직접 뛰어들 필요가 없습니다. 욜로세움에서는 검증된 유튜버 트레이더들의 전략이 자동매매 봇으로 구현되어, 당신을 대신해 24/7 시장과 싸웁니다. 

당신은 단지 누워서 포도를 먹으며, 어떤 검투사(봇)가 가장 뛰어난지 관전하고 선택하면 됩니다. 모든 전투 기록은 투명하게 공개되며, 에스크로 지갑을 통해 안전하게 자금을 관리합니다.

**YOLO하되, 똑똑하게.**

## 4. 타겟 고객

### Primary Target
**MZ세대 투자자 (25-35세)**
- 암호화폐/주식 투자 경험 있음
- 유튜브로 트레이딩 정보 습득
- 직장인으로 시간 부족
- 자동화 솔루션 선호
- YOLO 정신이지만 리스크는 관리하고 싶음

### Secondary Target
**베테랑 투자자 (35-50세)**
- 포트폴리오 다각화 원함
- 검증된 전략 선호
- 수동적 수익 추구
- 데이터 기반 의사결정

### User Persona

**"관전러 민수" (29세, IT 직장인)**
- 퇴근 후 트레이딩하기 힘듦
- 유튜브로 여러 트레이더 구독 중
- "이 사람들 전략을 자동으로 따라갈 수 있다면?"
- 수익률보다 안정성과 편의성 중요

## 5. 서비스 구조

### 핵심 기능

#### 1. 검투사 아레나 (Bot Arena)
```
┌─────────────────────────────────────┐
│  🥇 RANK 1: "김코인" Bot             │
│  수익률: +127% (30일)                │
│  승률: 68% | 팔로워: 15,234         │
│  [전략 보기] [탑승하기]              │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  🥈 RANK 2: "차트마스터" Bot         │
│  수익률: +98% (30일)                 │
│  승률: 72% | 팔로워: 12,890         │
│  [전략 보기] [탑승하기]              │
└─────────────────────────────────────┘
```

#### 2. 황제의 관람석 (User Dashboard)
- 내 포트폴리오 현황
- 탑승 중인 봇들의 실시간 수익률
- 과거 전투 기록 (히스토리)
- 배당 내역 (포도 수확)

#### 3. 에스크로 금고 (Escrow Wallet)
- 스마트 컨트랙트 기반 자금 보관
- 봇은 거래 권한만, 출금 권한은 사용자
- 투명한 수수료 구조 (성과 보수)

#### 4. 실시간 경기장 (Live Trading View)
- 봇들의 실시간 매매 현황
- 순위 변동 라이브 스코어보드
- 커뮤니티 채팅 (경기 해설)

### 수익 모델

| 티어 | 월 구독료 | 동시 탑승 가능 봇 | 수수료 할인 |
|------|-----------|------------------|-------------|
| 평민 (Free) | ₩0 | 1개 | 0% |
| 귀족 (Noble) | ₩29,000 | 3개 | 10% |
| 황제 (Emperor) | ₩99,000 | 무제한 | 20% |

**+ 성과 보수**: 수익의 10-15% (봇별 상이)

## 6. 마케팅 전략

### 런칭 캠페인: "검투사를 선택하라"

#### Phase 1: 티저 (2주)
- 콜로세움 폐허 영상 + "곧 전쟁이 시작됩니다"
- SNS: 황제 왕관과 포도 이미지만
- 해시태그: #욜로세움 #검투사는봇

#### Phase 2: 리빌 (1주)
- 서비스 정식 공개
- 유튜버 트레이더 10명과 파트너십 발표
- "당신의 전략이 봇으로 태어납니다"

#### Phase 3: 오픈베타 (1개월)
- 선착순 1,000명 황제 티어 무료
- 실시간 랭킹 공개
- 주간 최고 수익 봇에 "황금 월계관" 수여

### 콘텐츠 전략

#### 유튜브 시리즈
1. **"봇투사 열전"**: 각 봇의 전략 소개
2. **"황제의 선택"**: 유명인이 봇 선택하고 결과 공개
3. **"아레나 하이라이트"**: 주간 베스트 트레이드

#### 커뮤니티
- 디스코드: "욜로세움 원로원"
- 월간 "검투사 대회": 봇 간 수익률 경쟁
- UGC: 사용자들의 수익 인증 → "포도 수확 인증"

## 7. 브랜드 경험 (CX Journey)

### 1단계: 입장 (Onboarding)
```
"욜로세움에 오신 것을 환영합니다, 황제여!"
→ 간단한 설문 (투자 성향, 선호 전략)
→ AI 추천 봇 3개 제시
→ 무료 체험 (가상 자금 $10,000)
```

### 2단계: 관전 (Watching)
- 대시보드에서 실시간 수익률 확인
- 푸시 알림: "김코인 봇이 +5% 수익을 달성했습니다! 🍇"
- 주간 리포트: "이번 주 당신의 포도 수확량"

### 3단계: 참여 (Engaging)
- 봇 평가 및 리뷰 작성
- 다른 황제들과 전략 토론
- 새로운 봇 요청 (원하는 유튜버)

### 4단계: 수확 (Harvesting)
- 수익 출금 시 "포도 수확 애니메이션"
- 누적 수익 마일스톤 배지
- VIP 이벤트 초대 (오프라인 네트워킹)

## 8. 경쟁 우위

### VS 일반 자동매매 봇
- ❌ 출처 불명의 알고리즘
- ✅ 검증된 유튜버 트레이더 기반

### VS 카피 트레이딩
- ❌ 실시간 수동 복사, 지연 발생
- ✅ 완전 자동화, 즉시 체결

### VS 직접 투자
- ❌ 24/7 모니터링 필요
- ✅ 완전한 수동 소득

### 욜로세움만의 차별점
1. **엔터테인먼트 요소**: 투자를 게임처럼
2. **투명한 랭킹 시스템**: 실시간 리더보드
3. **커뮤니티 중심**: 함께 관전하는 재미
4. **브랜드 스토리텔링**: 단순 봇이 아닌 "검투사"
