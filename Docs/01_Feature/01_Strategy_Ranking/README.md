# 01. 전략 랭킹 시스템 (Strategy Ranking)

## 개요
플랫폼의 메인 페이지에 다양한 거래 전략들을 수익률, TVL(총 예치 자산), 위험 등급 등의 기준으로 정렬하여 사용자가 인기 있고 성과가 좋은 전략을 한눈에 파악할 수 있도록 제공하는 시스템.

## 주요 기능
- **전략 정렬:** 수익률, TVL, 위험 등급, 인기도 등 다양한 기준으로 정렬
- **전략 카드 UI:** 각 전략의 기본 정보(수익률, TVL, 위험도) 표시
- **콘텐츠 연동:** 유명 유튜브 트레이더의 설명 영상과 함께 제공
- **QR 코드:** 각 전략 Vault의 입금 주소를 QR 코드로 표시

## 기술 요구사항
- 프론트엔드: React / Next.js
- 백엔드: Node.js / Python 기반 데이터 API
- 데이터베이스: PostgreSQL (Vault 메타데이터 및 성과 지표 저장)

## 연관 피쳐
- 포트폴리오 모니터링
- 자동화 거래 실행
- 데이터 대시보드

## 개발 우선순위
**높음** - 사용자 유입의 핵심 인터페이스
