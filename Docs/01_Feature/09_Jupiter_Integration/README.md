# 09. DEX 통합 - Jupiter (Jupiter Integration)

## 개요
솔라나 생태계의 주요 DEX(Raydium, Serum, Orca 등)를 통합한 애그리게이터인 Jupiter를 플랫폼에 통합하여 최적의 거래 조건을 제공하는 시스템.

## 주요 역할
- **최적 경로 조회:** 여러 DEX의 유동성 풀을 분석하여 최적 거래 경로 제시
- **슬리피지 최소화:** 최선의 거래 가격으로 예상치 못한 손실 최소화
- **다양한 토큰 지원:** SOL과 주요 SPL 토큰 간 거래 지원
- **리밸런싱:** 포트폴리오의 자산 구성을 최적 비율로 자동 조정

## Jupiter API 활용
- **Quote API:** 교환 경로 및 예상 출력 조회
- **Swap API:** 실제 거래 실행
- **Token API:** 지원하는 토큰 목록 및 정보 조회

## 기술 요구사항
- **라이브러리:** Jupiter SDK (@jup-ag/api)
- **언어:** TypeScript / JavaScript (프론트엔드), Python (백엔드)
- **RPC Node:** 거래 서명 및 전송용
- **지갑 연동:** @solana/web3.js

## 거래 흐름
1. **사용자 입력:** 교환할 토큰 선택 및 수량 입력
2. **Quote 조회:** Jupiter Quote API로 예상 출력 및 경로 조회
3. **슬리피지 확인:** 사용자의 슬리피지 허용치 범위 확인
4. **거래 실행:** 사용자 서명 후 Jupiter Swap API 호출
5. **완료:** 거래 완료 및 토큰 수신 확인

## 지원 토큰
- **기본:** SOL, USDC, USDT
- **주요:** RAY, COPE, ORCA, mSOL, stSOL, scnSOL 등
- **확장:** 기타 주요 SPL 토큰

## 거래 수수료
- **Jupiter 수수료:** 거래액의 0.25% (거래 경로에 따라 상이)
- **프로토콜 수수료:** 각 DEX의 수수료 (Jupiter에 포함)
- **가스비:** SOL 네트워크 가스비 (보통 0.00025 SOL 미만)

## 슬리피지 관리
```
슬리피지 = (예상 출력 - 실제 출력) / 예상 출력 × 100%
사용자 설정 슬리피지: 0.1% ~ 1% 범위
```

## 이중화 및 폴백(Fallback)
- **기본:** Jupiter 사용
- **폴백:** Jupiter 실패 시 직접 DEX 호출
- **모니터링:** Jupiter API 가용성 지속적 모니터링

## 에러 처리
- **유동성 부족:** 거래 불가능 또는 슬리피지 초과
- **API 타임아웃:** 재시도 로직 구현
- **네트워크 지연:** 거래 확인 대기 및 타임아웃 설정
