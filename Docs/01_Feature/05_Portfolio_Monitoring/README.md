# 05. 포트폴리오 모니터링 (Portfolio Monitoring)

## 개요
사용자가 자신의 투자 포트폴리오를 실시간으로 모니터링하고, 각 Vault별 수익률, 거래 내역 등을 상세하게 추적할 수 있는 대시보드.

## 주요 기능
- **총자산 조회:** 모든 Vault에 예치된 자산의 총 가치 표시
- **Vault별 성과:** 각 Vault의 수익률, 초기 투자액, 현재 가치 표시
- **상세 거래 내역:** 각 Vault에서 발생한 모든 거래의 시간, 가격, 수익/손실 기록
- **실시간 업데이트:** 블록체인의 최신 데이터를 반영하여 실시간 갱신
- **수익률 차트:** 일별/월별 수익 추이를 그래프로 시각화

## 대시보드 구성
- **포트폴리오 요약:** 총자산, 총 수익, 수익률 퍼센트
- **Vault 목록:** 각 Vault별 예치액, 현재 가치, 수익률
- **거래 내역:** 거래 날짜, 유형(입금/출금/자동 거래), 금액, 수익/손실
- **성과 차트:** 시간대별 포트폴리오 가치 변화

## 기술 요구사항
- **프론트엔드:** React / Next.js, 차트 라이브러리 (Chart.js, Recharts)
- **백엔드:** Node.js / Python 기반 데이터 API
- **데이터베이스:** PostgreSQL (거래 기록 저장)
- **블록체인 데이터:** RPC Node (Helius, QuickNode)

## 데이터 소스
- 온체인 Vault 상태 (자산, 지분)
- 거래 이력 (블록체인 트랜잭션)
- 실시간 가격 데이터 (DEX 애그리게이터)

## 캐싱 전략
- 자주 변하는 데이터(가격, 잔액): 1-5분 갱신
- 거래 내역: 매 블록마다 동기화
- 포트폴리오 요약: 1분마다 계산

## 연관 피쳐
- 전략 랭킹 시스템
- 자동화 거래 실행
- 성과 수수료 계산

## 개발 우선순위
**높음** - 사용자 만족도의 중요 요소
