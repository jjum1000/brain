# 06. 자동화 거래 실행 (Automated Trading)

## 개요
스마트 컨트랙트가 사전 정의된 조건에 따라 자동으로 거래를 실행하고, 외부 실행자(Crank)를 통해 거래를 주기적으로 수행하는 시스템.

## 주요 기능
- **온체인 조건 기반 거래:** 가격, 시간, 기타 온체인 데이터 기반의 자동 실행
- **Crank 메커니즘:** 외부 실행자가 주기적으로 거래 조건을 확인하고 실행
- **DEX 애그리게이터 연동:** Jupiter를 통해 최적의 교환 비율로 거래 실행
- **슬리피지 관리:** 예상 가격과 실제 체결 가격 간 차이 제한
- **거래 기록:** 모든 거래가 온체인에 기록되어 투명성 확보

## 거래 실행 프로세스
1. **조건 정의:** 전략에 따른 거래 조건 설정
2. **조건 모니터링:** Crank가 주기적으로 조건 확인
3. **조건 충족 시:** Jupiter API를 통해 최적 거래 경로 조회
4. **거래 실행:** 스마트 컨트랙트에서 실제 거래 수행
5. **기록 저장:** 거래 내역을 온체인 및 DB에 저장

## 기술 요구사항
- **스마트 컨트랙트:** Vault 거래 로직 구현 (Anchor, Rust)
- **Crank 서비스:** 백엔드 서비스로 주기적 실행 (Node.js, Python)
- **DEX 통합:** Jupiter SDK/API 활용
- **RPC Node:** 온체인 데이터 접근 (Helius, QuickNode)

## Crank 메커니즘
- **실행 주기:** 전략별로 설정 (1분~1시간)
- **비용 최적화:** SOL 가스비를 고려한 효율적 실행
- **실패 처리:** 거래 실패 시 재시도 또는 로깅

## 거래 종류
- **스왑(Swap):** 토큰 교환 (SOL ↔ SPL 토큰)
- **유동성 제공:** 특정 풀에 유동성 추가
- **차익 거래:** 여러 DEX 간의 가격 차이 활용
- **마켓 메이킹:** 특정 가격대에서 자동 매수/매도

## 위험 관리
- 슬리피지 제한으로 예상치 못한 가격 변동 방지
- 최대 거래액 제한
- 일일 거래 한계 설정

## 연관 피쳐
- 비위탁 Vault 시스템
- DEX 통합 (Jupiter)
- 데이터 대시보드
- 백테스팅 시스템
