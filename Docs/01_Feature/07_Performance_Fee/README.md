# 07. 성과 수수료 계산 (Performance Fee)

## 개요
Vault에서 수익이 발생했을 경우에만 해당 수익의 일정 비율을 자동으로 징수하는 투명한 수수료 모델.

## 주요 원칙
- **수익 기반:** 손실이 발생하면 수수료 없음
- **자동 처리:** 스마트 컨트랙트에 의해 자동으로 징수
- **투명성:** 모든 수수료 징수 내역이 온체인에 기록
- **이해관계 일치:** 플랫폼과 사용자의 이익이 같음

## 수수료 구조
- **성과 수수료율:** 10% ~ 20% (전략별로 상이 가능)
- **고워터마크(High Water Mark):** 이전 최고가를 돌파했을 때만 징수
- **기타 수수료:** 없음 (입금, 출금, 관리 수수료 모두 없음)

## 수수료 계산 방식

### 고워터마크(High Water Mark) 방식
```
이전 최고 자산가 = HWM
현재 자산가 = NAV
수익 = NAV - HWM (NAV > HWM인 경우)
성과 수수료 = 수익 × 수수료율
새로운 HWM = NAV
```

## 수수료 징수 프로세스
1. **성과 계산:** 각 Vault의 수익을 주기적으로 계산
2. **조건 확인:** HWM을 초과했는지 확인
3. **수수료 계산:** 순이익에 수수료율 적용
4. **토큰 생성:** 수수료에 해당하는 LP 토큰 생성 또는 현금 전환
5. **지갑 전송:** 징수된 수수료를 플랫폼 주소로 전송
6. **기록 저장:** 모든 수수료 거래를 온체인 및 DB에 기록

## 기술 요구사항
- **스마트 컨트랙트:** 수수료 자동 계산 및 징수 로직
- **백엔드:** 수수료 현황 및 통계 API
- **데이터베이스:** 수수료 거래 내역 저장
- **모니터링:** 수수료 징수 오류 추적

## 사용자 관점
- **수수료 조회:** 포트폴리오 페이지에서 누적 수수료 확인 가능
- **수수료 상세:** 거래 내역에서 각 수수료 징수 기록 상세 조회
- **영향 계산:** 수수료 적용 전/후 수익률 비교 가능

## 플랫폼 관점
- **수익 추적:** 전체 수수료 수익 현황 대시보드
- **Vault별 분석:** 각 Vault의 수수료 통계
- **지갑 관리:** 징수된 수수료 지갑 관리

## 투명성 및 감시
- 모든 수수료 계산이 스마트 컨트랙트 코드에 명시
- 블록체인 익스플로러에서 모든 수수료 거래 확인 가능
- 제3자 감시 가능

## 연관 피쳐
- 비위탁 Vault 시스템
- 자동화 거래 실행
- 포트폴리오 모니터링

## 개발 우선순위
**높음** - 플랫폼 지속성의 핵심
