# 04. 자금 입출금 (Deposit/Withdraw)

## 개요
사용자가 선택한 전략 Vault에 SOL 또는 SPL 토큰을 입금하거나, 자신의 지분에 해당하는 자산을 출금할 수 있도록 하는 기능.

## 주요 기능
- **입금(Deposit):** SOL 및 지원하는 SPL 토큰을 Vault에 입금
- **출금(Withdraw):** 사용자 지분만큼의 자산을 즉시 출금
- **지분 계산:** 입금액에 따른 LP 토큰 발행 및 관리
- **거래 상태 추적:** 펀딩/출금 거래의 진행 상황 모니터링

## 기술 요구사항
- **스마트 컨트랙트:** Vault의 입출금 로직 구현
- **프론트엔드:** 사용자 UI 및 거래 폼
- **백엔드:** 거래 기록 및 지분 추적 API

## 프로세스 흐름
1. 사용자가 입금할 금액 및 토큰 선택
2. 지갑 연결을 통해 거래 서명
3. 스마트 컨트랙트에서 자산 수신
4. LP 토큰 발행
5. 거래 완료 및 블록 확인

## 출금 프로세스
1. 사용자가 출금할 지분 비율 선택
2. 거래 서명
3. Vault에서 해당 자산 출금
4. LP 토큰 소각
5. 자산 전송 완료

## 수수료 정책
- **입금/출금 수수료:** 없음
- **성과 수수료:** 수익 발생 시에만 징수 (별도 기능)

## 안전성 고려사항
- 거래 슬리피지 관리
- 재진입 공격 방어
- 정확한 지분 계산

## 연관 피쳐
- 비위탁 Vault 시스템
- 지갑 연동

## 개발 우선순위
**매우 높음** - 핵심 거래 기능
