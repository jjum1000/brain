# 10. 데이터 대시보드 (Data Dashboard)

## 개요
플랫폼의 모든 주요 지표를 시각화하여 사용자 및 운영자가 한눈에 플랫폼 상황을 파악할 수 있는 관리자/분석 대시보드.

## 주요 섹션

### 1. 플랫폼 개요 (Platform Overview)
- **총 TVL(Total Value Locked):** 모든 Vault에 예치된 자산의 총가
- **활성 사용자:** 현재 활성인 사용자 수
- **전체 거래수:** 누적 거래 건수
- **총 수수료:** 누적 성과 수수료

### 2. Vault 분석 (Vault Analytics)
- **Vault 목록:** 각 Vault의 이름, 전략, 수익률, TVL
- **수익 순위:** 수익률 기준 상위 Vault
- **TVL 순위:** 예치액 기준 인기 Vault
- **위험도 분석:** 각 Vault의 MDD, 변동성 등

### 3. 거래 통계 (Trading Statistics)
- **일일 거래량:** 일별 총 거래액
- **평균 거래액:** 거래당 평균 거래액
- **거래 빈도:** 시간당/일당 거래 건수
- **성공률:** 성공 거래 비율

### 4. 사용자 지표 (User Metrics)
- **신규 사용자:** 일별 신규 가입자
- **사용자 보유:** 누적 사용자 수
- **활동 사용자:** 최근 7일 활성 사용자
- **사용자별 평균 투자액:** 사용자당 평균 예치액

### 5. 수익 분석 (Revenue Analysis)
- **총 수수료:** 누적 성과 수수료
- **일일 수수료:** 일별 수수료
- **Vault별 수수료:** 각 Vault의 수수료 기여도
- **수수료 분배:** 개발팀/마케팅/예비금 분배 현황

## 기술 요구사항
- **프론트엔드:** React / Next.js
- **차트 라이브러리:** Chart.js, Recharts, D3.js
- **백엔드:** Node.js / Python 기반 분석 API
- **데이터베이스:** PostgreSQL (데이터 저장)
- **캐싱:** Redis (자주 조회되는 통계 캐시)
- **실시간 업데이트:** WebSocket (실시간 데이터 업데이트)

## 데이터 수집
- **온체인 데이터:** RPC Node (Helius, QuickNode)
- **거래 이력:** 블록체인 트랜잭션 분석
- **사용자 데이터:** 자체 데이터베이스
- **시장 데이터:** Jupiter, CoinGecko 등 외부 API

## 캐싱 전략
- **실시간:** TVL, 활성 사용자 (1분 갱신)
- **준실시간:** 거래 통계 (5분 갱신)
- **일일:** Vault 순위, 월간 통계 (1시간 갱신)

## 권한 관리
- **공개:** 전략 랭킹, 플랫폼 개요 (누구나 조회 가능)
- **사용자:** 포트폴리오 대시보드 (본인 데이터만 조회)
- **관리자:** 전체 분석 및 통계 (관리자만 조회)

## 차트 및 시각화
- **시계열 차트:** TVL, 거래량, 수익률 추이
- **파이 차트:** 자산 구성, 수수료 분배
- **히트맵:** 거래 활동 분포
- **테이블:** 상세 거래 내역, Vault 목록

## API 엔드포인트
```
GET /api/dashboard/overview       # 플랫폼 개요
GET /api/dashboard/vaults         # Vault 목록 및 순위
GET /api/dashboard/trading-stats  # 거래 통계
GET /api/dashboard/user-metrics   # 사용자 지표
GET /api/dashboard/revenue        # 수익 분석
GET /api/vaults/:id/analytics     # 특정 Vault 분석
```

## 성능 최적화
- 데이터 페이지네이션 (대량 데이터 분할)
- 동적 로딩 (필요한 차트만 로드)
- 캐싱 활용 (자주 조회되는 데이터)
- CDN 배포 (정적 자산 최적화)

## 연관 피쳐
- 전략 랭킹 시스템
- 포트폴리오 모니터링
- 성과 수수료 계산
- 자동화 거래 실행

## 개발 우선순위
**중간-높음** - 사용자 신뢰도 및 플랫폼 투명성 확보
