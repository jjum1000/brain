# 02. 비위탁 Vault 시스템 (Non-Custodial Vault)

## 개요
각 거래 전략을 스마트 컨트랙트 기반의 Vault로 구현하여, 사용자가 자신의 자산에 대한 완전한 통제권을 유지하면서도 자동화된 거래를 수행하는 핵심 시스템.

## 주요 특징
- **비위탁(Non-Custodial):** 플랫폼 운영자도 사용자 자산에 접근 불가
- **개인키 기반 통제:** 사용자가 자신의 개인키로만 입출금 가능
- **스마트 컨트랙트 기반:** Anchor Framework로 개발된 Solana 프로그램
- **투명한 규칙:** 모든 거래 규칙이 코드로 명시되어 외부 감사 가능

## 핵심 기능
- Vault 생성 및 초기화
- 자산 입금 (Deposit)
- 자산 출금 (Withdraw)
- 자산 관리 및 추적
- 자동화 거래 실행 (Crank 또는 온체인 조건 기반)
- 성과 수수료 자동 징수

## 기술 스택
- **블록체인:** Solana
- **언어:** Rust
- **프레임워크:** Anchor Framework
- **테스트:** Devnet/Testnet

## 개발 단계
1. 전략 설계 및 검증
2. 스마트 컨트랙트 개발
3. 단위 및 통합 테스트
4. 외부 보안 감사
5. 메인넷 배포

## 리스크 관리
- 재진입(Re-entrancy) 공격 방어
- 가격 조작 방지
- 권한 탈취 방지
- 멀티시그 지갑을 통한 관리자 권한 제한

## 개발 우선순위
**매우 높음** - 플랫폼의 핵심 인프라
